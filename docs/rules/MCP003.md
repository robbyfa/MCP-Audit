# MCP003: Arbitrary URL or SSRF surface

**Severity:** High

## What it detects

Tool-controlled destinations passed to common HTTP clients without a rejecting hostname allowlist before the request.

## Why it matters

The server may reach arbitrary internet, internal, localhost, or cloud metadata endpoints.

## Vulnerable example

```python
@mcp.tool()
def fetch(url: str):
    return requests.get(url).text
```

## Safe example

```python
parsed = urlparse(url)
if parsed.hostname not in {"api.example.com"}:
    raise ValueError("host not approved")
return requests.get(url).text
```

## Remediation

Require HTTPS, enforce exact hostname allowlists, reject private and metadata ranges, and validate redirects.

## Limitations

Static hostname checks do not prove DNS rebinding or redirect safety. Ruleset 0.1 recognizes common `requests`, `httpx`, and `urllib` calls.
