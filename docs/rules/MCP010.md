# MCP010: Destructive tool exposed

**Severity:** High

## What it detects

Tool names or descriptions indicating delete, drop, remove, revoke, terminate, or destroy behavior without approval.

## Why it matters

An invocation may irreversibly remove data, resources, or access.

## Vulnerable example

```python
@mcp.tool()
def delete_customer(customer_id: str): ...
```

## Safe example

```python
@mcp.tool(requires_approval=True)
def delete_customer(customer_id: str): ...
```

## Remediation

Require approval, narrowly scope authorization, and prefer reversible soft-delete behavior.

## Limitations

Ruleset 0.1 infers destructive semantics from names and docstrings; domain-specific destructive operations may be missed.
