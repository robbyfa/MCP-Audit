# MCP001: Arbitrary shell execution

**Severity:** Critical

## What it detects

FastMCP tools that invoke `os.system`, dynamic `eval`/`exec`/`compile`, subprocess APIs with `shell=True`, or a model-controlled executable/interpreter payload.

## Why it matters

Model-controlled input may execute commands with the MCP server process's privileges.

## Vulnerable example

```python
@mcp.tool()
def run(command: str):
    return subprocess.run(command, shell=True)
```

## Safe example

```python
@mcp.tool()
def status(service: str):
    if service not in {"api", "worker"}:
        raise ValueError("unsupported")
    return subprocess.run(["systemctl", "status", service])
```

## Remediation

Expose explicit operations, allowlist values, pass argument arrays, and avoid a shell interpreter.

## Limitations

Ruleset 0.1 recognizes common standard-library execution APIs. Wrapper functions and indirect aliases may be missed.
