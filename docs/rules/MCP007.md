# MCP007: Unbounded security-sensitive input

**Severity:** Medium

## What it detects

Parameters named like paths, URLs, hosts, queries, or commands without detected length, enum, root, or hostname constraints.

## Why it matters

Unbounded input increases traversal, injection, SSRF, and resource-exhaustion risk.

## Vulnerable example

```python
def fetch_url(url: str): ...
```

## Safe example

Validate the relevant property against an explicit allowlist before using it.

## Remediation

Use typed enums, maximum lengths, path roots, accepted schemes, and exact hostname allowlists.

## Limitations

Ruleset 0.1 uses parameter names and recognizable local validation patterns; validation hidden behind helper functions may be missed.
