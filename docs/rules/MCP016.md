# MCP016: Capability escalation

**Severity:** High

## What it detects

A new high-impact tool or an existing tool whose filesystem, network, execution, side-effect, destructive, financial, or data-access capability expands relative to a Git baseline.

## Why it matters

Existing clients may silently gain broader authority during an ordinary code change.

## Vulnerable example

```text
network: allowlisted_hosts -> unrestricted_outbound
```

## Safe example

An unchanged capability, or a change from unrestricted access to an allowlist.

## Remediation

Constrain the capability or explicitly review and approve the new manifest baseline.

## Limitations

Renamed tools appear as removed and added. Ruleset 0.1 compares statically inferred capabilities rather than runtime authorization policy.
