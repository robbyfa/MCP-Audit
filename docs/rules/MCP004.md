# MCP004: High-impact side effect without approval

**Severity:** Medium for external writes; High for destructive actions

## What it detects

Tools that appear to send, publish, modify externally, or destroy state without an approval decorator or rejecting approval guard.

## Why it matters

A mistaken or malicious invocation can cause consequential real-world actions without confirmation.

## Vulnerable example

```python
@mcp.tool()
def send_webhook(url: str, payload: str):
    return requests.post(url, data=payload)
```

## Safe example

```python
@mcp.tool(requires_approval=True)
def send_webhook(url: str, payload: str):
    return requests.post(url, data=payload)
```

## Remediation

Require explicit approval and enforce scoped authorization at execution time.

## Limitations

Name-based side-effect classification uses whole semantic tokens to avoid substring matches such as `post` in `PostgreSQL`. It can still miss domain-specific verbs or flag descriptive names that do not perform an action.
