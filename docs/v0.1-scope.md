# MCP Audit V0.1 Scope

V0.1 focuses on local Python/FastMCP source scanning and security regression signals.

Implemented:

- FastMCP-style `@mcp.tool()` discovery.
- Capability extraction for filesystem, network, execution, side effects, destructive actions, financial hints, and approval hints.
- Rule findings for MCP001, MCP002, MCP003, MCP004, MCP005, MCP007, MCP010, MCP016, and MCP017.
- Terminal, JSON, and SARIF output.
- Capability manifest generation.
- Basic policy thresholds and suppressions.
- Git baseline diff command.
- Structured evidence with source snippets, impact, and remediation.
- Data classification and destination context for MCP005 capability paths.
- Regression-focused terminal and JSON diff reports.
- Reusable composite GitHub Action with SARIF upload.

Accuracy corpus:

- Direct and allowlisted shell execution.
- Restricted and unrestricted filesystem access.
- Arbitrary, allowlisted, fixed, and superficially inspected URLs.
- Destructive actions with and without approval.
- Sensitive read-only servers and sensitive-to-network paths.
- Git capability escalation and report-schema tests.
- Golden terminal, JSON, SARIF, manifest, and diff contracts.
- Reasoned suppressions with optional expiry.
- Per-rule behavior and limitation documentation.
- Copyable vulnerable FastMCP pull-request scenarios.

Deferred:

- Runtime MCP inspection.
- TypeScript scanning.
- Hosted dashboard and GitHub App.
- Active attack harness.
- Legal compliance determination.

MCP Audit produces technical evidence only. It must not claim legal compliance from a passing scan.
